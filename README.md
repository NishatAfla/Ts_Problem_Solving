# TypeScript Programming Problem Solving

## Questions

### Question 1: Difference Between Maximum and Second Maximum
Given an array of numbers, find the difference between the maximum value and the second maximum value.

### Question 2: Sum of Prime Numbers
Given an array of numbers, calculate the sum of all prime numbers.

### Question 3: Sum of Unique Elements After Removing Duplicates
Remove duplicate values from an array and calculate the sum of the unique elements.

### Question 4: Find the Missing Number
Find the missing number from an array using the formula:

`n * (n + 1) / 2 - sumOfArray`

### Question 5: Count Occurrence of Each Number
Count how many times each number appears in an array.

### Question 6: Return Repetitive Elements
Return only the elements that appear more than once in an array.

### Question 7: Print Unique Characters from a String
Print all unique characters from a string and count the total number of unique characters.

### Question 8: Print All Permutations of a String
Print all possible permutations of a given string and count the total number of permutations.

### Question 9: Generate a Random Password
Generate a random password containing at least:
- One uppercase letter
- One lowercase letter
- One numeric digit
- One special character

### Question 10: Remove All Special Characters
Remove all special characters from a given string.

### Question 11: Remove All Vowels from a String
Remove all vowels from a given string.

### Question 12: Check Valid Binary Number
Check whether a given string is a valid binary number.

### Question 13: Extract Digits and Calculate Discounted Total
Extract the required numeric values from a paragraph and calculate the final cost after applying the discount.

### Question 14: Currency Note Breakdown
Break down a given amount into the minimum number of currency notes.

### Question 15: Find 5-Mark and 10-Mark Questions
Determine the number of 5-mark and 10-mark questions required to make exactly 100 marks.

# Installation

## 1. Clone the repository

```bash
git clone <repository-url>
```

## 2. Open the project folder

```bash
cd Ts_problemSolving
```

## 3. Install TypeScript

```bash
npm install typescript --save-dev
```

---

# Compile TypeScript Files

Compile all TypeScript files:

```bash
npx tsc
```

This generates the corresponding JavaScript (.js) files.

---

# Run a Program

Run any program using Node.js.

Example:

```bash
node qs1.js
```

For other questions:

```bash
node qs2.js
node qs3.js
node qs4.js
...
node qs15.js
```
